# Alisio — Maspalomas Ground Station Watch

An unofficial, illustrative 3D world of the Maspalomas ground station receiving real Copernicus Sentinel passes, computed in the browser.

Work in progress.

## Spec note: coast (amended R4.1)

The coast is shown as "coast direction and relative distance indicated with a label; geometry compressed for legibility and marked illustrative". The sea lies south of the station, and the in-scene label reads "coast (compressed, illustrative)". The real shoreline is not scale-consistent with the campus.
